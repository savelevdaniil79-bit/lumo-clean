## Команды
    npm run build:content     # собрать lumo_complete_content.json из src/
    npm run validate:partial  # качество уже написанного (код 0 = ошибок нет)
    npm run validate:content  # строгая итоговая приёмка (48/384/1920)
    npm run verify:code       # реально запускает Python из вопросов и сверяет ответы
    npm run check             # build + validate:partial + verify:code

## Как добавить курс
1. Создайте `src/batches/<courseId>/index.js` (courseId — из `src/registry.js`), экспортируйте массив из 8 уроков (см. `python-beginners`).
2. Используйте помощники из `src/lib/h.js`: `lesson`, `sel` (4 варианта + объяснение каждого неверного), `inp`, `mat`, `L(ru,en,uz)`, `N(нейтральный текст)`.
3. ID вопросов и уроков назначаются автоматически: `<courseId>.l01`, `<courseId>.l01.q01`. Не меняйте их после выдачи.
4. `npm run check`.

## Перенос прогресса учеников
`legacy_id_map.json` связывает старые id (`co1`…, числовые id курсов) с новыми стабильными. Нужен адаптеру при подключении контента к сайту, чтобы не потерять прогресс из `localStorage` (`lumo.v2`).

## Формат
См. `lumo_complete_content.json`. Типы вопросов: `single_select` (4 варианта), `true_false` (2), `text_input` (`acceptedAnswers`), `matching` (`pairs`). Поле `verify` служебное (для `verify:code`), импортёр должен его игнорировать.
